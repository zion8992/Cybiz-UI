# Cybiz UI

*A clean, dark mode UI for Cubyz*

## How to install

### Manually (easy, does NOT auto-update)

1. Head to the releases page [here](https://github.com/zion8992/Cybiz-UI/releases)
2. Download the latest release

### Using Git (more technical, auto-updates)

#### Install (Do this once)

1. Open your Cubyz install folder (it contains `Cubyz`, `launchConfig.zon`, and `assets`).
2. Delete everything inside `assets/cubyz/ui`.
3. From `assets/cubyz`, clone the UI repository. This creates a `Cybiz-UI` folder.
4. Rename `Cybiz-UI` to `ui`.

#### Update

1. Open your Cubyz install folder (it contains `Cubyz`, `launchConfig.zon`, and `assets`).
2. From `assets/cubyz/ui`, run `git pull` to update the texture pack.
3. That's all!

## Supported Cubyz Versions

- `0.4.2`
- `0.4.1`
